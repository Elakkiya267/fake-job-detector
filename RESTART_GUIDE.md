# Quick Restart Guide

## 🔄 To Apply Updates

### Step 1: Stop Current Servers
If backend is running, press `Ctrl+C` in the terminal

### Step 2: Restart Backend
```bash
cd c:\Users\elakk\OneDrive\Desktop\fake-job-postings-app\backend
python app.py
```

### Step 3: Refresh Browser
- If frontend is open, just press `F5` or `Ctrl+R`
- Or open fresh: `http://localhost:8000`
